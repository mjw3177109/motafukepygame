# Static floor placement -> Pygame/Canvas drawing adapters

Source of *placement rules*: `game.swf` SHA256 `04b317b7fd9d32c5b083c993e99a3eea527f392e5fc938d23928e953bb638db9`, FFDec Java 8 export `export/scripts/frame_4346/DoAction_2.as` SHA256 `0de19a0338cd966446acb4fd2acb82f82cf77992c8839356e17afc8f3085d034`. Existing `core/floor_tile_plan.py` / `web/floor_tile_plan.mjs` supply the original sprite source aliases, map coordinates and Flash depths.

This patch adds **real drawing adapters**, not just placement plans: `blit_floor_plan(pygame_surface, plan, assets)` and `drawFloorPlan(canvas_context, plan, assets)` draw supplied image surfaces in ascending depth order, with explicit source-specific registration offsets. A complete asset entry is `{image, origin_x, origin_y}`. **Offsets must be measured from the exported SWF sprites**; using arbitrary zeros or tilesheets is not verified parity. The renderers deliberately do not invent image files, sprites, offsets, or animations.

Both adapters preflight *every* placement before drawing. Missing source image/registration metadata, duplicate instance, invalid depth/position, or a plan without pending refresh and input lock raises an error **before any draw call**. The renderers never clear the background, advance Flash timelines, apply alpha/blend modes, mutate the map, signal `floor_refresh_complete`, or unlock input. They do not resolve Flash display-list transforms, source registration, depth overlap, animated clips, or pixel parity. An exception during an actual surface draw may still produce a partial frame; callers should draw to an offscreen surface before presenting it.

Regression tests use fake Pygame-like surfaces and fake Canvas contexts to verify actual draw invocations, depth order, registration offset arithmetic, missing-asset atomic preflight, and preserved lock state. **These mocks do not prove the real game displays correctly.** Next: extract and catalog actual `mt_*` source sprites, measure registration/transform metadata, then run real Pygame and browser screenshot comparisons with original Flash. RL/Kaggle gate remains closed.
