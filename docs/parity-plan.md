## 证据文件格式

`evidence/original.jsonl` 与 `evidence/pygame.jsonl` 等轨迹要求同序的每条 JSON 对象包含 `action` 和 `state`，且其余可比较字段也需严格一致。录屏截图需额外比对，不能以 JSON 轨迹测试代替视觉验收。

在 `evidence/parity_signoff.json` 记录经核实的原版 SHA256、两个运行端的审核和通关视频及回放引用。程序化签字**不自动意味着真实 1:1**，仍须审阅附件。

## 强化学习阶段

先把已验证的相同规则包成 `Gymnasium` 环境，进行小地图 deterministic reset / step / reward / done / invalid-action 测试，再在 Kaggle GPU 上进行 PPO/DQN/分层策略基线实验。通关验证必须以**真实游戏运行的完整回放**为准，不接受模拟玩具环境的成功率。
